### 本版内容

**支持平台**

- B站（`bilibili.com` / `b23.tv` / `bili2233.cn`）
- 抖音（`douyin.com` / `v.douyin.com` / `iesdouyin.com`）
- Twitter / X

**解析**

- 完整链接、**分享文案**、短链、**裸 ID**（BV 号 / av 号 / 抖音作品 ID / `modal_id=` 参数）均支持
- 抖音精选页弹窗播放（`?modal_id=`）可直接解析
- 多级兜底：RENDER_DATA → `_ROUTER_DATA` → DOM → 分享页
- 抖音新增**不开浏览器的轻量解析**，通常 1~2 秒出结果

**下载**

- 多线程分片下载（HTTP Range），绕过 CDN 单连接限速
- **并发自适应**：从 2 条起步，按实测吞吐自动升降；无提升会自动回退并提示瓶颈在链路
- **CDN 测速择优选址**：下载前实测各 CDN 速度，按快慢排序，失败自动切下一个
- **断连韧性**：单片自动重试 → 缺口记录 → 最后低并发补下；连接中断主动降并发
- 完整性按分片集合校验，不会产出截断文件
- 支持随时取消（自动清理半成品）
- 实时显示速率 / 剩余时间 / 已下载大小

**平台能力**

- B站：多P选择、清晰度选择、**仅音频 MP3**、**弹幕 XML**、**字幕 SRT**
- 抖音：**去水印**、无声检测与自动换源

**Cookie 管理**

- 一键扫码登录（自动弹出登录框并切到扫码页；登录态持久化，二次免扫码）
- 整段粘贴自动规整（抖音几十段 Cookie 只保留 4 个关键字段）
- 兼容 JSON 导出、`Cookie:` 请求头前缀、甚至只贴一个裸值
- **有效期离线检测**：解析 Cookie 内部到期时间，状态栏显示真实状态，快到期自动提醒

**界面**

- 粘贴即解析、拖拽入窗、`Ctrl+Enter` 解析 / `Ctrl+L` 清空
- 下载队列：并发可配、失败一键重试、任务置顶、取消、打开文件
- 历史记录、托盘完成通知、关闭确认、重复下载提示、文件名模板
- 滚动日志落盘（设置 → 打开日志目录）

### 已知限制

- **走 VPN / 代理时多线程可能无法提速**：若瓶颈是隧道总带宽，程序会识别并自动回退到低并发（日志会提示"链路总带宽可能是瓶颈"）。这是链路限制，非程序问题。
- 抖音**合集 / 分P**尚未支持批量下载，一个链接对应一个视频。
- 抖音若服务端只提供 DASH 分离流，个别视频仍可能无音轨（日志会给出明确警告）。
- 输出格式仅支持 `mp4` / `mp3`。
